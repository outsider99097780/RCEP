# 局限与待补数据

1. HS850980 是产品组代理，不是扫地机器人专属编码统计；需要海关归类决定、企业报关口径或更细粒度产品线数据进行确认。
2. EPM 的 `baseline_exports_usd` 与 Trade Map 的年度双边出口额存在口径/年份差异，不应直接当作同一字段相加或替换。
3. ITC 数据不能识别 Roborock 品牌、具体型号、零售定价、销量或品牌市占率；这些信息需由企业公告、零售商页面、第三方市场研究或当地销售数据补充，并单独标注来源等级。
4. 老挝、缅甸、越南等市场的 Trade Map 关键字段存在缺失或覆盖不足；未将缺失值当作 0，也未将这些市场强行纳入排名。
5. 关税以 ITC 返回的税则线和适用税率为准；`850980` 下存在多个目的国 NTL，不能把某一条税则线自动推广到所有扫地机型号。
