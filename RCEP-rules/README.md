# RCEP 贸易分析资料包（中国出口 HS 850980/85098090）

访问与整理日期：2026-09-05（Asia/Shanghai）

## 用途

本资料包服务于“中国向其他 RCEP 成员出口产品”的贸易分析，重点覆盖：

- 货物贸易与关税承诺；
- 原产资格、累积规则、区域价值成分、微小含量；
- 原产地证书、原产地声明、背对背证明和直接运输；
- 海关程序、技术性贸易措施与贸易救济；
- 各目的国对中国货物适用的 RCEP 关税承诺表；
- HS 8509.80/8509.80.90 的产品特定原产地规则和关税表行级提取。

这是一套“原始官方文件 + 可复核提取 + 分析提示”的证据包，不代替海关归类裁定、进口国当期税则或法律意见。

## 最重要的使用前提

用户给定的中国海关编码为 `85098090.00`。但 HS 85.09 的品目文字是“装有自备电动机的家用电动器具，但品目 85.08 的真空吸尘器除外”。因此，如果所研究的“扫地机器人”核心功能和结构构成真空吸尘器，应优先核对是否归入 85.08，而不是直接沿用 85098090。报告中不得把产品俗称当成海关归类结论。

建议在使用本资料包前，取得中国海关预裁定/归类依据，或至少保留产品说明书、吸尘结构、电机、过滤与集尘方式等归类证据。

## 税率使用警告

关税承诺表中的 `Year 1...Year 20` 是协定承诺路径，不等同于任意查询日的实际适用税率。实际税率还受以下因素影响：

- 各成员生效日期及“年份”的表头定义；
- HS 转版和本国税则拆分；
- 更低的当期 MFN 税率；
- 暂时性减免、保障措施、反倾销/反补贴；
- 是否满足原产地规则、直接运输和证明文件要求。

因此，模型可把本包中的承诺路径作为制度变量，但最终“当前实际适用税率”应与进口国海关税则、ITC Market Access Map 或具日期的报关查询结果交叉核验。
