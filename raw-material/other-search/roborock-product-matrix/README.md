# Roborock 产品矩阵资料包

本目录保存石头科技官网扫地机器人产品矩阵及其可追溯来源。

- `roborock_product_matrix.json`：20个型号/系列的结构化矩阵，含功能、吸力、官方页面、官方图片URL和来源标签。
- `roborock_product_matrix.md`：便于报告和答辩引用的中文矩阵。
- `images/`：从 Roborock 官方站 CDN 下载的20张产品图。
- `union_search_official_success.json`：union-search 单源成功响应，平台返回10条、跨结果去重后保留5条。
- `union_search_global.json`、`union_search_us.json`：union-search 多源响应，保留查询、平台、时间戳和部分平台失败记录。

产品信息以2026年9月14日官网展示为准。`matrix_role` 和“场景标签”是本组根据官网功能作出的产品组合分析，不是官网原文。
