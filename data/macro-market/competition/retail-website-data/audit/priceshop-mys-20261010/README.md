# PriceShop 马来西亚数据复核

`inputs/` 保存本轮选定公开事实的采集输入，不是完整网页镜像。原始网页缓存的精确时间戳不可得，`source_cache_age_raw` 仅保留阅读器当时显示的相对标签。访问时间不冒充报价生效时间。

`verify.py --data-root <retail-website-data目录>` 可以只读重算商品报价中位数、按商家组平衡的中位数，核对原始报价、参数和来源哈希；不联网，不改文件。

`reader_fact_extractor.js` 是本轮从公开网页阅读器结果中提取字段的逻辑，依赖采集环境中的存储接口，不是对 PriceShop 发起请求的爬虫。网页完整正文没有归档，不能声称能从本地完整重放网页解析；可以从已保存的事实快照复核所有价格计算和结构化输出。

`build.py` 是一次性更新构建器，运行时需要更新前的项目基线及同级 `captures/` 输入；它会在同级 `publish/` 中生成候选文件，不直接写入项目。不要在已更新项目上再次执行该迁移器，否则追加台账的重复检查会停止。后续复核请使用只读 `verify.py`。发布时覆盖文件已在任务工作区备份；没有删除原始记录或其他国家文件。

来源和适用范围见 `analysis/priceshop_MYS_20261010.md`。44个商品页的阅读器返回内容已读完，但全站目录及所有商家分页未核验；五品牌完整实时采集未完成。云鲸只有历史价格证据，不是当前在售价格。
