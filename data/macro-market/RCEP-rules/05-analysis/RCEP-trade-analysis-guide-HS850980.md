# RCEP 贸易分析指南：从中国出口 HS 850980/85098090

整理日期：2026-09-05

## 一、研究中最有用的协定条款

| 主题 | 主要条款 | 对模型/报告的用途 |
|---|---|---|
| 关税减让 | 第 2.4 条 | 原产货物按附件一承诺表降税；若进口时 MFN 实施税率更低，可适用更低 MFN 税率。不要只看承诺表。 |
| 关税差异 | 第 2.6 条 | 当进口国对不同 RCEP 出口方给出不同税率时，需要确定“RCEP 原产国”，不能仅以最后出口国替代。 |
| 商品归类 | 第 2.7、2.14 条 | 成员间贸易按协调制度归类；税表转版不得削弱承诺。必须记录 HS 版本和本国税号映射。 |
| 非关税措施 | 第 2.16—2.19 条 | 约束不透明或不必要的 NTM、数量限制和进口许可；适合构造市场准入/合规成本指标。 |
| 原产货物 | 第 3.2 条、附件 3A | 判断完全获得、完全使用原产材料生产，或满足产品特定规则。 |
| 累积 | 第 3.4 条 | 其他 RCEP 成员的原产材料可视为本方原产材料；有利于区域供应链安排。 |
| RVC | 第 3.5 条 | 规定区域价值成分计算。若选择 `RVC40` 路径，应保留 FOB、非原产材料价值和计算底稿。 |
| 微小含量 | 第 3.7 条 | 未满足税则归类改变的非原产材料，在规定限度内可能仍可被容许；不能把它误解成普遍免除 RVC。 |
| 微小加工 | 第 3.6 条 | 仅包装、简单装配等不足以赋予原产资格。 |
| 直接运输 | 第 3.15 条 | 经第三方运输时需保持海关监管、不得进行超出卸装/保存所需的加工，并保存运输证据。 |
| 原产地证明 | 第 3.16—3.18 条、附件 3B | 明确证书、原产地声明和最低信息；是否可用声明取决于出口方资质与各方实施状态。 |
| 背对背证明 | 第 3.19 条 | 区域分拨/转运时可基于原证明开具背对背证明，需保留原证明编号、日期和原产国等。 |
| 第三方发票 | 第 3.20 条 | 第三方开票本身不应使货物失去优惠资格，但证明中信息必须一致且可核验。 |
| 申请与补申请 | 第 3.22、3.23 条 | 规范进口时申请优惠和进口后申请退税/补享优惠；实际期限依进口方法律。 |
| 核查与拒绝 | 第 3.24、3.25 条 | 原产地证据可能接受书面核查、访问核查；资料不完整或不回复可导致拒绝。 |
| 记录保存 | 第 3.27 条 | 建立 BOM、采购凭证、成本表、生产记录、运输文件、证书和报关资料的同一证据链。 |
| 海关便利化 | 第 4 章，特别是预裁定、货物放行、风险管理、易腐/快件条款 | 将通关时间、预裁定可得性、AEO/风险管理作为市场便利度指标。 |
| TBT | 第 6 章 | 扫地机属于电器产品，市场分析应另查安全、电磁兼容、能效、无线模块、电池和合格评定要求。RCEP 并不自动取消各国技术法规。 |
| 贸易救济 | 第 7 章 | 即使表内优惠为零，仍可能出现保障、反倾销或反补贴措施；应作为风险项单独检查。 |

条款原文见 `01-agreement/` 中相应章节的中英文 PDF。

## 二、HS 8509.80 的现行产品特定原产地规则

RCEP 秘书处发布的 HS 2022 转版产品特定原产地规则在第 118 页列明：

> `8509.80 - Other appliances — CTSH or RVC40`

含义：

- `CTSH`：非原产材料在生产后发生六位 HS 子目改变；或
- `RVC40`：区域价值成分不低于 40%。

二者是可选择路径，不要求同时满足。正式申报时必须结合第 3 章定义、计算规则和进口国实施要求，并在证明文件中填写正确的原产标准。

### RVC 的常用计算框架

协定允许按照第 3.5 条规定的方法计算。研究底稿至少保存：

- FOB 价值及币种；
- 每项非原产材料价值、原产国和归类；
- RCEP 原产材料及累积依据；
- 直接成本、间接成本和会计期间；
- 计算公式、舍入规则和复核人。

模型中不要用“国产化率”口头估计替代 RVC。若 BOM 数据不足，应把原产资格标记为“未证实”，而不是默认合格。

### 不能直接得出的结论

- 上表不是“2026 年实际税率表”。
- 表中不降税不等于实际进口一定缴该税率；第 2.4 条允许适用更低的 MFN 实施税率。
- 同一六位 HS 在各国可能拆成不同 8/9/10 位税号，必须以进口国品目描述匹配。
- 不满足原产规则时不能使用 RCEP 优惠，但仍可能适用 MFN 或其他协定税率。

## 四、建议加入市场吸引力模型的制度变量

| 指标 | 建议测量 | 证据来源 |
|---|---|---|
| 当期实际适用税率 | 有效日期下的 RCEP 对华税率；与 MFN 取可合法适用者 | 进口国海关/ITC Market Access Map；本包承诺表用于复核 |
| 关税优惠幅度 | MFN 实施税率减 RCEP 税率 | 同上 |
| 原产合规可行性 | CTSH 可满足性、RVC、区域累积比例 | BOM、供应商声明、本包 PSR |
| 证明便利度 | 电子 CO/电子 PO 接受、经核准出口商制度、自助打印 | `02-origin/` 的最新状态和中国实施文件 |
| 技术合规负担 | 安全、EMC、能效、无线、电池、回收责任的项目数与成本 | 各国主管机关；第 6 章只作制度框架 |
| 通关便利度 | 预裁定、平均放行时间、AEO、数字化水平 | 各国海关与第 4 章 |
| 贸易救济风险 | 是否有现行调查/措施、保障风险 | 各国主管机关、WTO、ITC |

## 五、可审计分析流程

1. **归类确认**：分别记录中国 10 位税号、RCEP PSR 六位子目、进口国本国税号和 HS 版本。
2. **原产资格预判**：对 BOM 同时测试 CTSH 和 RVC40，保留哪个路径更稳健以及失败原因。
3. **税率查询**：先读表头说明和对华/通用表，再查有日期的进口国实际税率；同时记录 MFN。
4. **证明路线**：确认使用签证机构证书、经核准出口商声明还是背对背证明；核对电子接受状态。
5. **运输路线**：若经非缔约方中转，保存提单、仓储、海关监管和未加工证明。
6. **非关税合规**：单独建立产品认证、标签、能效、无线、电池和环保义务清单。
7. **建模**：所有制度变量绑定来源文件、页码/条款、访问日期和有效日期；缺失值不得默认成零。
8. **敏感性分析**：分别用“能取得 RCEP 优惠”和“不能取得优惠、使用 MFN”两种情景计算市场得分。
