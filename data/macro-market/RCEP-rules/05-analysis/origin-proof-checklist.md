# RCEP 原产地证明与证据链检查表

适用对象：中国出口人、生产商及研究人员。此表依据 RCEP 第 3 章、附件 3B、实施指南和中国海关实施规则整理。

## 1. 归类与规则

- [ ] 产品技术资料足以支持 HS 归类，不仅有商品名称。
- [ ] 记录中国出口税号、RCEP 六位 HS、进口国税号及各自 HS 版本。
- [ ] 确认适用的 HS 2022 PSR；8509.80 为 `CTSH or RVC40`。
- [ ] 明确选择 CTSH 还是 RVC40，并保存完整测试底稿。
- [ ] 若使用累积，保存 RCEP 原产材料的有效证明。
- [ ] 排除仅有包装、简单装配等“微小加工”的情形。

## 2. BOM 与生产证据

- [ ] 成品 BOM、料号、用量和版本锁定。
- [ ] 每项材料的供应商、原产国、HS 子目和原产性质已记录。
- [ ] 采购发票、供应商声明、入库与领料记录可相互勾稽。
- [ ] 生产工序、地点、日期和批次可追溯。
- [ ] RVC 路径保存 FOB、非原产材料价值、汇率和计算表。
- [ ] CTSH 路径保存所有非原产材料与成品的六位 HS 对照。

## 3. 原产地证书最低信息（附件 3B）

- [ ] 出口人名称和地址。
- [ ] 生产商名称和地址（已知时）。
- [ ] 进口人或收货人名称和地址。
- [ ] 货物描述及六位 HS 编码。
- [ ] 原产地证书编号。
- [ ] 原产标准。
- [ ] 出口人或生产商声明。
- [ ] 签证机构的认证、授权签名和官方印章。
- [ ] 第 2.6 条所指 RCEP 原产国。
- [ ] 发票号、启运日期、船名/航班号、卸货港等货运识别信息。
- [ ] 使用 RVC 标准时填写 FOB 价值。
- [ ] 货物数量。
- [ ] 背对背证书还应填写原证明编号、签发日期、首次出口方的 RCEP 原产国及适用时的经核准出口商代码。

## 4. 原产地声明最低信息（附件 3B）

- [ ] 出口人名称和地址。
- [ ] 生产商名称和地址（已知时）。
- [ ] 进口人或收货人名称和地址。
- [ ] 货物描述及六位 HS 编码。
- [ ] 经核准出口商的授权/识别代码（适用时）。
- [ ] 唯一参考编号。
- [ ] 原产标准。
- [ ] 授权签字人证明货物符合第 3 章。
- [ ] RCEP 原产国。
- [ ] 使用 RVC 标准时填写 FOB 价值。
- [ ] 货物数量。
- [ ] 背对背声明包含原证明编号、日期、首次出口方 RCEP 原产国及适用时的授权代码。

## 5. 运输与进口申请

- [ ] 商业发票、装箱单、提单/空运单与证明信息一致。
- [ ] 第三方发票已正确披露，未改变货物身份。
- [ ] 中转路线满足直接运输要求。
- [ ] 经第三方中转时保存海关监管、仓储和未进一步加工证据。
- [ ] 已确认进口国是否接受电子 CO/电子原产地证明。
- [ ] 已确认进口申报时点、补申请/退税期限和文件语言要求。

## 6. 归档与核查准备

- [ ] 为每批次分配唯一证据包编号。
- [ ] 证书/声明、报关单、发票、运输和生产资料彼此可勾稽。
- [ ] 记录制作人、复核人、日期和版本。
- [ ] 对海关核查请求设定责任人与答复时限。
- [ ] 依法保存记录；若本国和进口国期限不同，采用更长的业务保存期。
